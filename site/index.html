How it works

An idea becomes a draft, a draft becomes an approved calendar entry, a scheduler hands it to a connector, and the results come back as numbers the agent can learn from.

Principles

The calendar is the only way out

Agents create and edit entries. They never publish and never approve. A scheduler fires approved entries when their time comes.

Approval tiers

Tier 1 passes automatically, tier 2 needs one click, tier 3 is a deliberate manual approval. When unsure, the higher tier wins.

Agents get tools, not keys

Agents use the bb brandwise CLI, also over MCP. API keys live in settings and are never shown to them.

Swap providers freely

Statistics hang on our own records, so replacing the e-mail provider does not break reports.

What is inside

AreaWhat it does
CampaignsAn always-on base (brand or product) plus time-bound campaigns that inherit from it.
CalendarMonth and week views, approval queue, change requests, retries and failure reasons.
CreativesLibrary of images and videos in S3, thumbnails, AI provenance, upload and CRUD.
PublishingConnectors for Telegram and e-mail (Resend); channels without a connector wait as "Publish by hand".
E-mailProvider-neutral events, counts and a metric catalog: opens, clicks, bounces, rates.
GenerationImage and video generation with per-call and daily credit limits.
Video (optional)Remotion projects per campaign, Remotion Studio next to an agent chat.
Agents"Start agent" in the side panel of every page; it knows which page and project you are on.

Architecture

A bb plugin over a small core on Postgres and S3. Connectors and providers are modules you can add without touching the rest.

Quick start

Requires Node 24, Docker, bb 0.48 or newer and rsync.

git clone https://github.com/amirmamaghani/brandwise.git
cd brandwise
cp .env.example .env
npm run infra:up                 # Postgres and an S3 emulator
infra/bb-instance/provision.sh up

export BB_SERVER_URL=http://127.0.0.1:38896 BB_HOST_DAEMON_PORT=38897
bb brandwise campaign list       # "Main brand" is created on first start

Telegram and e-mail switch on when their credentials are in .env. Details are in the README and CONTRIBUTING.
